# Cholos in Paris

**Cholos in Paris** es una web-app para que artistas organicen su catálogo musical, desarrollen proyectos y visualicen cómo podrían presentarse sus lanzamientos en distintas plataformas. El producto es desarrollado por **Sharksites**.

## Un espacio para crear y organizar música

La aplicación reúne canciones, proyectos y perfil artístico en un solo lugar. Cada artista administra su propio espacio y puede preparar material antes de publicarlo en las vistas de simulación.

- **Catálogo:** consulta canciones en formato de lista o portadas, busca y filtra por título, fecha y estado.
- **Canciones:** edita título, fecha, portada, audio, letra y artistas colaboradores. El historial de versiones permite seguir el avance desde la composición hasta el master.
- **Proyectos:** crea álbumes o EPs, añade canciones existentes y organiza el orden del tracklist.
- **Perfil artístico:** administra nombre, descripción, foto y banner, además de las preferencias de apariencia.
- **Reproductor:** reproduce las pistas cargadas, permite recorrer el audio y ofrece controles de reproducción, volumen, letra y cola.

Las imágenes se pueden ajustar desde la aplicación antes de guardarlas. Las canciones y proyectos pueden mantenerse como borradores o publicarse en las vistas de simulación.

## Vistas de plataformas

La web-app incluye vistas de simulación inspiradas en Spotify, YouTube, SoundCloud y Apple Music. Muestran canciones y proyectos marcados como publicados, junto con sus portadas, fechas, artistas colaboradores y datos de reproducción disponibles.

Estas vistas sirven como previsualización dentro de Cholos in Paris: no publican ni distribuyen música en las plataformas reales.

## Tecnología

La interfaz está construida con HTML, CSS y JavaScript, con diseño adaptable a computadora y teléfono. Firebase proporciona autenticación, base de datos y almacenamiento de archivos. El acceso admite Google, Apple y correo electrónico cuando los proveedores correspondientes están habilitados.
